# Rasc Web

Commercial website and marketing source repository for Rasc.

Rasc is a native Mac scratchpad for unfinished thoughts. This repository combines approved commercial/landing direction with verified product facts, real app design tokens, current brand-source provenance, and the marketing capture plan.

The macOS application lives at /Users/rafatorres/Desktop/rasc and remains the source of truth for current product behavior, UI, design tokens, build/version, and real product captures.

## Current state

- Approved positioning, narrative, landing IA, and Brand Identity v1 are documented.
- This is a source/specification repository; no landing frontend has been implemented or scaffolded.
- Current app raster identity sources are preserved for provenance. They are distinct from a verified final brand master.
- Product UI shown on the website must come from real app captures when available. The website may frame the product but must not fake its interface.
- No speculative product features or app-behavior changes belong in this repository.
