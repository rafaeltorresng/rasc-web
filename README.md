# Rasc Web

Commercial website and marketing asset repository for Rasc.

Rasc is a native Mac scratchpad for unfinished thoughts.

This repository contains:

- commercial positioning;
- landing narrative and information architecture;
- brand identity;
- design references;
- marketing assets;
- website implementation.

The macOS application lives in a separate repository and remains the
source of truth for product behavior, UI, design tokens and real screenshots.
