# Real app capture

`rasc-scratchpad-beta4.png` was captured through the native macOS app on 8 October
2026, from the beta.4/build 5 Release candidate after its build and regression
checks. It is a 1440 × 880 capture of the 720 × 440 scratchpad in dark appearance.
No UI, text or model result was composited or generated for the image.

The temporary audit copy used a distinct bundle identifier and an empty sandbox,
so no personal notes/database were read or copied. Text was explicitly entered
as a synthetic public example. The copy was ad-hoc signed for this local check;
the capture does not certify a notarized/public binary.

The animated HTML scenes elsewhere on the landing are illustrations derived from
product behavior, not screenshots or a live AI endpoint. Refresh this capture if
the final release changes the visible UI. The same image is included in the app
repository at `docs/images/scratchpad.png`.
